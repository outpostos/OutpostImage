# Story 1.1: 初始化 Go 项目结构

## Status: Approved

## Story

**As a** 开发者,
**I want** 一个参考 Spegel 布局的 Go 项目结构和可运行的服务骨架,
**so that** 后续所有 Epic 有统一的基础设施可以构建在上面。

## Acceptance Criteria

1. `go build .` 编译通过
2. 目录结构参考 Spegel 布局（main.go 根目录、pkg/、internal/）
3. `go mod init github.com/outpostos/outpostimage` 模块初始化完成
4. main.go 使用 `alexflint/go-arg` 解析 subcommand
5. 使用 `errgroup` 管理 goroutine 生命周期
6. `signal.NotifyContext` 处理 SIGTERM/SIGINT

## Tasks / Subtasks

- [ ] Task 1: 初始化 Go module (AC: 3)
  - [ ] 运行 `go mod init github.com/outpostos/outpostimage`
  - [ ] 添加核心依赖：go-arg, errgroup, go-digest, image-spec, prometheus, go-logr, fsnotify

- [ ] Task 2: 创建目录结构 (AC: 2)

  - [ ] 每个包放置一个 `doc.go` 占位文件（package 声明 + 注释）

- [ ] Task 3: 实现 main.go 入口 (AC: 1, 4, 5, 6)
  - [ ] 使用 `alexflint/go-arg` 定义 RegistryCmd 子命令结构体

  - [ ] 使用 `signal.NotifyContext(ctx, syscall.SIGTERM, syscall.SIGINT)` 创建根 context
  - [ ] 使用 `errgroup.Group` 框架（目前为空，后续 Epic 填充）
  - [ ] 打印启动日志（listen addresses）
  - [ ] `go build .` 编译通过

- [ ] Task 4: 创建 Makefile (AC: 1)
  - [ ] `make build` → `go build -o bin/outpostimage .`
  - [ ] `make test` → `go test ./...`
  - [ ] `make lint` → `golangci-lint run` (如果可用)
  - [ ] `make clean` → 清理构建产物

## Dev Notes

### 项目结构参考

参考 Spegel 项目布局，main.go 放在根目录（不使用 cmd/ 子目录）：

```
outpostimage/
├── main.go              # 入口
├── go.mod
├── Makefile
├── internal/            # 内部工具（不导出）
│   ├── channel/
│   ├── cleanup/
│   └── option/
├── pkg/                 # 核心业务包
│   ├── oci/             # Store interface + adapters
│   ├── registry/        # OCI Registry API Server
│   ├── proxy/           # HTTP Proxy
│   ├── routing/         # Router + Balancer
│   ├── state/           # State tracker
│   ├── metrics/         # Prometheus
│   └── httpx/           # HTTP 工具
├── charts/outpostimage/ # Helm Chart
├── deploy/              # Docker Compose
└── docs/                # 文档
```

### go-arg 配置结构体参考

```go
type RegistryCmd struct {
    RegistryAddr string `arg:"--registry-addr,env:REGISTRY_ADDR" default:":5000" help:"Registry API listen address"`
    ProxyAddr    string `arg:"--proxy-addr,env:PROXY_ADDR" default:":3128" help:"HTTP Proxy listen address"`
    MetricsAddr  string `arg:"--metrics-addr,env:METRICS_ADDR" default:":9090" help:"Metrics listen address"`
    LogLevel     string `arg:"--log-level,env:LOG_LEVEL" default:"INFO" help:"Log level (DEBUG, INFO, WARN, ERROR)"`
}
```

### errgroup 生命周期管理参考

```go
ctx, cancel := signal.NotifyContext(context.Background(), syscall.SIGTERM, syscall.SIGINT)
defer cancel()

g, ctx := errgroup.WithContext(ctx)

// 后续 Epic 在这里添加 g.Go(...)

if err := g.Wait(); err != nil {
    slog.Error("service stopped", "error", err)
    os.Exit(1)
}
```

### 命名规则

- Package: 小写单词，不用下划线
- 导出类型: PascalCase
- 文件: 小写，下划线分隔
- 常量: PascalCase (导出)

### Testing

- 测试与源码同目录，`_test.go` 后缀
- 优先 stdlib `testing`
- 此 Story 主要是结构搭建，确保 `go build .` 通过即可
