# Story 2.4: Digest Query API

## Status: Approved

## Story

**As a** P2P 集群中的其他节点,
**I want** 通过 HTTP API 查询本节点拥有哪些 digest,
**so that** 可以在拉取镜像时判断是否从该节点获取。

## Acceptance Criteria

1. `GET /api/v1/digests` 返回 JSON 格式 digest 列表
2. `GET /api/v1/digests/{digest}` 查询单个 digest 存在性
3. 查询不存在的 digest 返回 404
4. 响应时间 < 10ms（内存查询）

## Tasks / Subtasks

- [ ] Task 1: 实现 digest 列表 API (AC: 1)
  - [ ] 注册到 registry server mux
  - [ ] 从 State Tracker 获取 digest 列表

- [ ] Task 2: 实现单个 digest 查询 API (AC: 2, 3)
  - [ ] 路由匹配 /api/v1/digests/{digest}
  - [ ] 存在返回 200，不存在返回 404

- [ ] Task 3: 单元测试 (AC: 4)
  - [ ] 测试 digest 列表返回
  - [ ] 测试单个 digest 查询 200/404
