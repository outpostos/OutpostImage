# Story 2.3: State Tracker

## Status: Approved

## Story

**As a** 系统组件,
**I want** State Tracker 在启动时全量扫描构建索引，并持续订阅存储变更事件,
**so that** 内存中的 digest 索引始终与本地存储保持一致。

## Acceptance Criteria

1. 启动时调用 Store.ListImages() 构建初始索引
2. 订阅 Store.Subscribe() 事件流，处理 CREATE/DELETE 事件
3. 提供线程安全的 digest 查询接口
4. 索引内存占用 < 50MB (1000 layers, NFR4)

## Tasks / Subtasks

- [ ] Task 1: 实现 Track 函数 (AC: 1, 2)
  - [ ] 启动时全量扫描 ListImages
  - [ ] 构建 map[digest.Digest]bool 索引
  - [ ] 订阅 Subscribe 事件流，增量更新索引

- [ ] Task 2: 提供查询接口 (AC: 3)
  - [ ] HasDigest(dgst) bool
  - [ ] AllDigests() []digest.Digest
  - [ ] 线程安全（sync.RWMutex）

- [ ] Task 3: 单元测试 (AC: 4)
  - [ ] 测试初始扫描
  - [ ] 测试事件驱动增量更新
  - [ ] 测试并发安全
