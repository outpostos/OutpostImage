# Story 6.3: Kubernetes DaemonSet 部署

## Status: Done

## Story

**As a** 边缘平台 DevOps 工程师,
**I want** 通过 Kubernetes DaemonSet 一键部署 OutpostImage 到集群所有节点,
**so that** 每个节点自动运行 P2P 镜像分发代理，无需手动安装。

## Acceptance Criteria

1. `kubectl apply` 部署到 K8s 集群成功
2. DaemonSet 在每个节点运行一个 Pod
3. Pod 可访问宿主机 Docker 存储 (`/var/lib/docker` 只读挂载)
4. ConfigMap 提供 peers 配置示例
5. Docker Compose 部署方案可用（已完成于 6-2）
