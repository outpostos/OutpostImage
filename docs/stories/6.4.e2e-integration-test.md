# Story 6.4: 端到端集成测试

## Status: In Progress

## Story

**As a** 开发者,
**I want** 一个自动化的端到端集成测试套件,
**so that** 可以验证 P2P 镜像分发流程在多节点场景下正常工作。

## Acceptance Criteria

1. P2P 拉取成功率 100%
2. P2P hit rate >= 60%
3. 回退场景拉取成功（所有 peer 不可用时）
4. 测试报告包含 pull duration 和 bandwidth 数据

## Tasks / Subtasks

- [ ] Task 1: 创建多节点模拟环境 (AC: 1, 2)
  - [ ] Mock OCI Store 支持注入测试数据
  - [ ] 3 节点 HTTP server 并行运行

- [ ] Task 2: P2P 发现与拉取测试 (AC: 1, 2)
  - [ ] Node 1 有镜像，Node 2/3 通过 P2P 发现并拉取
  - [ ] 验证 digest 查询 API 正确路由
  - [ ] 验证 blob 内容完整性

- [ ] Task 3: 回退场景测试 (AC: 3)
  - [ ] 所有 peer 不可用时，请求回退处理

- [ ] Task 4: 性能指标收集 (AC: 4)
  - [ ] 记录 pull duration
  - [ ] 记录 bandwidth 节省比
