# Story 1.4: 结构化日志

## Status: Approved

## Story

**As a** 运维工程师,
**I want** 服务输出结构化 JSON 日志，并有 HTTP 访问日志中间件,
**so that** 可以在边缘节点上方便地搜索、过滤和分析日志。

## Acceptance Criteria

1. 默认输出 JSON 格式日志到 stderr
2. `--log-level=DEBUG` 时可见 debug 级别日志
3. 每个 HTTP 请求产生一条访问日志（method, path, status, duration）

## Tasks / Subtasks

- [ ] Task 1: slog 已在 Story 1.1 配置完成，验证 JSON 输出 (AC: 1, 2)
  - [ ] 已使用 slog.NewJSONHandler(os.Stderr, ...)
  - [ ] 已支持 --log-level 参数

- [ ] Task 2: 创建 HTTP 访问日志中间件 (AC: 3)
  - [ ] 在 pkg/httpx/ 中创建 logging.go
  - [ ] 记录 method, path, status, duration
  - [ ] 应用到 registry server 和 metrics server

- [ ] Task 3: 单元测试
  - [ ] 测试中间件记录正确的字段
  - [ ] 测试状态码捕获
