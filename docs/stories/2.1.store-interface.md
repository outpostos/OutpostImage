# Story 2.1: Store 接口定义

## Status: Approved

## Story

**As a** 开发者,
**I want** 在 pkg/oci/ 中定义统一的 Store 接口和相关数据结构,
**so that** Docker 和 containerd 适配器可以实现统一接口，上层组件无需关心底层存储差异。

## Acceptance Criteria

1. 接口定义在 `pkg/oci/store.go`
2. 包含完整的 GoDoc 注释
3. 编译通过
4. 定义 Image, Reference, OCIEvent 数据结构

## Tasks / Subtasks

- [ ] Task 1: 定义 Store 接口 (AC: 1, 2, 3)
  - [ ] Name() string
  - [ ] ListImages(ctx) ([]Image, error)
  - [ ] Resolve(ctx, ref) (digest.Digest, error)
  - [ ] GetManifest(ctx, dgst) ([]byte, string, error) -- content + mediaType
  - [ ] GetBlob(ctx, dgst) (io.ReadCloser, int64, error) -- reader + size
  - [ ] HasBlob(ctx, dgst) bool
  - [ ] Subscribe(ctx) (<-chan OCIEvent, error)

- [ ] Task 2: 定义数据结构 (AC: 4)
  - [ ] Image: Digest, RepoTags, Size
  - [ ] OCIEvent: Type (CREATE/DELETE), Digest, Image
  - [ ] EventType constants

## Dev Notes

### 参考 Spegel oci.Store

Spegel 的 Store 接口定义在 `pkg/oci/oci.go`，我们的设计参考其模式但简化。

### opencontainers/go-digest

使用 `github.com/opencontainers/go-digest` 类型来表示 content-addressable digest。
