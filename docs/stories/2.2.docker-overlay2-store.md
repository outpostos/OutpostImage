# Story 2.2: Docker overlay2 Store 实现

## Status: Approved

## Story

**As a** 开发者,
**I want** 实现 DockerStore 适配器，读取 Docker overlay2 本地存储,
**so that** 可以索引本地镜像并通过 OCI Registry API 暴露给集群其他节点。

## Acceptance Criteria

1. 给定本地已有镜像，`ListImages()` 返回包含该镜像的列表
2. `GetManifest(ctx, digest)` 返回合法的 OCI manifest JSON
3. `GetBlob(ctx, configDigest)` 返回可读的 image config 数据
4. 对不存在的 digest，`HasBlob()` 返回 false
5. `Subscribe()` 通过 fsnotify 监听 imagedb 变更

## Tasks / Subtasks

- [ ] Task 1: 解析 repositories.json (AC: 1)
  - [ ] 解析 repo:tag → config digest 映射
  - [ ] 构建内存索引

- [ ] Task 2: 读取 imagedb 中的 image configs (AC: 1, 3)
  - [ ] 扫描 imagedb/content/sha256/ 目录
  - [ ] 解析 image config JSON 提取 rootfs.diff_ids

- [ ] Task 3: 实现 Store 接口方法 (AC: 2, 3, 4)
  - [ ] ListImages, Resolve, GetManifest, GetBlob, HasBlob
  - [ ] ChainID 计算 (diffID → chainID)
  - [ ] CacheID 查找 (chainID → overlay2 目录)

- [ ] Task 4: 实现 Subscribe (AC: 5)
  - [ ] fsnotify 监听 imagedb 目录变更

- [ ] Task 5: 单元测试
  - [ ] 使用临时目录构造 Docker 存储 fixtures
  - [ ] 测试 repositories.json 解析
  - [ ] 测试 ListImages, HasBlob
